# Minutes for Speakr

## Platform
Native Flutter Windows desktop; existing mobile layout remains supported.

## Users and purpose
Chinese-speaking users recording meetings and listening back to recordings on their own Speakr server. Primary workflow: recording library → capture microphone/system audio → playback, transcript, summary and questions.

## Constraints
Preserve real server data, existing recording/upload logic, shortcuts, source selection and secure credential storage. Do not invent collaboration or recycle-bin functionality from concept images. The user approved the neutral audio-workspace direction on 2026-10-28.
